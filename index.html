COURSE · 第一節

把選單上的數字，變成看得見的電波

用一台 RTL-SDR，把頻率、功率、天線、頻寬、步進、亞音、offset、靜噪一個一個「指」給你看。這是第一節課程的完整網頁版。

今天的路線九段主題 ＋ 三段實作 ＋ 一個分組任務： ① 瀑布圖 · ② 頻率 · ③ 發射功率 · ④ 天線 · ⑤ 寬/窄頻 · ⑥ 頻道步進 · ⑦ 亞音 · ⑧ Offset · ⑨ 靜噪，中間穿插動手做與「架一座中繼台」的想一想，最後用一個地震通聯任務收尾。
SESSION 1

頻譜 Spectrum & 瀑布圖 Waterfall

先學會讀這張圖——它是後面每一段共用的工具。

破除迷思　「看到訊號，就是有人在發」 → 有些是接收機自己生的假訊號。

1·1一張圖，兩層資訊

SDR 的畫面上下兩塊，其實是同一份資料的兩種畫法：上圖看「此刻」，下圖看「歷史」。

  • 橫軸 ＝ 頻率（上下兩圖共用）：訊號在左右哪裡，就是頻率多少。
  • 上圖 · Y 軸 ＝ 即時強度：此刻每個頻率有多強（dBFS，相對值）。
  • 下圖 · 往下 ＝ 時間流動：新的在上、舊的往下捲，看得到歷史。
  • 下圖 · 亮度 ＝ 強度：把上圖的「高度」換成「顏色深淺」，越亮越強。
一句話亮度＝相對強度，由你設的色階決定；訊號攤多寬＝佔用頻寬。

1·2瀑布圖上會遇到的五個詞

  • 1
    載波 Carrier

    被調變的那根基礎電波；沒說話時就是圖上乾淨的一根線。

  • 2
    底噪 Noise Floor

    沒有訊號時的背景雜訊；一切強度都跟它比高低。

  • 3
    頻寬 Bandwidth

    一個訊號左右攤開的寬度，決定它佔多少頻譜。

  • 4
    頻段 Band

    一段頻率的用途分區；圖上紅色標的「2m 業餘段」就是一個。

  • 5
    DC 尖峰 DC Spike

    接收機自己在正中央產生的假訊號，PTT 放開也不會消失。

什麼是「2m 業餘段」？波長約 2 公尺（144–148 MHz）的業餘無線電頻段——我們整堂課的手持機都在這裡。

1·3先有標準答案：理想的頻譜長什麼樣

│
純載波沒調變

沒說話、沒資料——就是一根線。

┃┃┃
FM ＋ 單音一排等距的線

純音調變（測試音、亞音）長出可數的邊帶。

◠◠
FM 語音一坨連續的丘

真人講話＝很多頻率混在一起，邊帶糊成一片。

▟▙
數位訊號一塊平頂方塊

資料把整段頻寬填滿，像一堵牆。

關鍵FM 一「調變」就長出邊帶。用純音（測試音 1kHz、亞音 88.5Hz）→ 一根一根數得出來；用真人語音 → 糊成一坨。所以後面 W/N、亞音的「多根」是正常的。

1·4沒看過的訊號，怎麼判斷真假？

不用看過，用常識推理三個問題：

  1. 它有理由待在這裡嗎？真訊號有來源與用途，會落在已知頻段；頻譜的無人地帶突然冒出東西，可疑。
  2. 形狀配得上用途嗎？語音要一定寬度、資料更寬、信標很窄——寬度不合理就存疑。
  3. 行為像真的嗎？會來會走＝有人通話；規律週期＝機器；一整排完美等距＝多半是你自己過載。

還是不確定？動手戳它一下：

按 PTT

  • 跟著你亮滅的 ＝ 真
  • 不理你的 ＝ 假

移中心頻率

  • 真訊號不動
  • 鏡像／DC 假訊號跟著中心跑
再一招降功率：真訊號掉一點；過載假峰掉更多、甚至消失。
SESSION 2

頻率 Frequency

大家最常碰到的參數——它在哪，以及它怎麼傳播。

破除迷思　「頻率越高，一定傳越遠」 → 看環境；VHF、UHF 各有各的場子。

2·1為什麼要對頻率？

★ 頻率對不上，其他全部免談——這是通訊的第一道門。
要解決的問題
空中同時有無數訊號。你要跟誰通，就得先和對方站到「同一個頻率」上。
設計原理
頻率＝事先約好的碰面地點；雙方對齊，才聽得到彼此。功率、天線都是之後的事。
現場場景
聽得到卻叫不到 → 先核對頻率與末位數字，比換天線、加功率都優先。

2·2頻率 ＝ 水平位置

轉一個頻道，那根線就往右跳一格 →

一句話頻率就是這根線的左右位置。聽得到卻叫不到，先查頻率末位數字，比查天線還優先。

2·3VHF 與 UHF：住在頻譜的哪裡

VHF 30 – 300 MHz

  • ← 頻率低 · 波長長
  • 2m 業餘段　144 – 148 MHz
  • 145 MHz → λ ≈ 2.07 m（「2 米」段）

UHF 300 MHz – 3 GHz

  • 頻率高 · 波長短 →
  • 70cm 業餘段　430 – 440 MHz
  • 435 MHz → λ ≈ 0.69 m（「70 公分」段）
波長公式λ = 光速 c ⁄ 頻率 f（c ≈ 3 × 10⁸ 公尺/秒）。頻率越高，波長越短。
一句話波長由頻率決定；波長決定了天線多大、以及電波怎麼傳——這是下一段的重點。

2·4波長長短，各有各的場子（理論上）

VHF · 2m 波長長（約 2 公尺）

  • 繞射強　能繞過山丘、地形起伏
  • 開闊佔優　郊區、野外傳得更遠
  • 天線較長　但增益容易做出來
  • 適合　山區、野外、長距離

UHF · 70cm 波長短（約 0.7 公尺）

  • 直線性強　靠反射鑽進建築、走廊
  • 穿透雜亂　市區、室內、大樓密集佔優
  • 天線較短　頻寬也較充裕
  • 適合　都市、室內、複雜地形
一句話沒有哪個「比較好」——看你在什麼環境。這是理論；真實世界還有下一段的變數。

2·5但理論歸理論：電波在真實環境會被折騰

多路徑 Multipath

  • 同一訊號走不同路徑到達，彼此相加相消 → 忽強忽弱

反射 Reflection

  • 牆面、金屬、水面把電波彈開，產生第二條路徑

折射 Refraction

  • 大氣與對流層讓路徑彎曲，訊號方向偏掉

散射 Scattering

  • 雨、樹葉、粗糙表面把能量打散到四面八方

繞射 Diffraction

  • 從山稜、建築邊緣繞過去，障礙後也收得到一點

吸收 / 遮蔽 Absorption

  • 牆體、人體、雨水吸掉能量，大障礙後形成陰影
加起來 ＝訊號飄移、衰落、時好時壞。「理論上更好」≠「現場更好」——走幾步、轉正天線就不同。先看，再猜。

2·6近代想辦法克服——但 FM 是類比

近代數位通訊怎麼對付不穩定

  • 數位調變 + 錯誤更正 (FEC)　收到有錯，靠冗餘碼自己補回來
  • 展頻 / OFDM　把資料攤到多個載波，避開被打爛的頻段
  • 分集 / MIMO　多支天線同時收，挑最好的那條路
  • 自適應編碼 + 重傳　通道差就降速、要求重送

業餘 FM 手持機 ＝ 類比，沒有這些

  • 簡單、堅固、低延遲的即時語音
  • 不需要基地台或網路就能通
  • 跨廠牌互通，靠人與紀律運作
  • 當基礎設施倒下，它還會動 ← 民防／災害的最後手段

抗噪靠 FM 捕獲效應，不靠演算法——訊號差就是差。所以前面每個參數都得調對。

一句話業餘無線電的定位：在最壞情況下——沒電、沒網、沒基地台——仍然會動的通訊。
SESSION 3

發射功率 TX Power

H / M / L —— 功率大，只是線更亮。

破除迷思　「功率越大越好」 → 夠用就好；大只是更耗電、更燙、干擾更廣。

3·1為什麼要有 H / M / L？

要解決的問題
訊號會隨距離變弱。功率決定你「推得多遠」，但推得越遠，也干擾越廣、越耗電。
設計原理
給你 H / M / L 三段可選，讓你按需要挑——夠用就好，不是越大越好。
現場場景
近距離用 L：省電、少干擾、機殼不燙；只有邊緣地帶才加到 H。

3·2功率 ＝ 高度 / 亮度（寬度不變）

功率大 ＝ 訊號更高、更亮，但左右寬度完全不變。通不通，還要看對方收不收得到——加功率不保證通。

實測（Narrow 窄頻，加 −20 dB 衰減）H ≈ −47 dB、L ≈ −51 dB——高度差看得出來（功率＝高度／亮度），而左右寬度一樣。先把訊號拉離天花板（衰減／拉遠），H 與 L 的差異才顯現。
SESSION 4

天線 Antenna

增益 ＝ 把功率集中打出去；頻率、接頭要對得上。

先想清楚　「天線隨便接就好」 → 頻率要對、增益看場景、接頭要對得上，接錯就白費功率。

4·1天線增益實測：換一支天線，載波差約 13 dB

同條件替換法：只換發射端天線、其他不動，讀 FFT 峰值相減。

長 − 短 ≈ 13 dB長天線把能量集中 → 載波明顯更強。
替換法量測條件MTS 發純載波 145.050 MHz（Wide／低功率／−20 dB 衰減）；RTL-SDR 固定接收（Gain 0、AGC 全關）。兩張噪聲底一致（約 −100 dB）＝條件相同。
註這是室內相對讀數（含短天線效率低＋近場／反射），非 dBi 認證增益值；但「長 > 短」順序正確，符合「天線越長、增益越高、載波越強」。要認證數字需室外遠場。

4·2挑天線看三件事：頻率、增益、接頭

① 頻率

  • 天線有設計頻段（例：FM 136–174 / 400–480MHz ＝ V/U 雙頻）。
  • 用在對的頻段才有效率；不對會 SWR 高、功率被反射回機身。

② 增益 gain

  • 常見 dBi / dBd（dBd ＝ dBi − 2.15）。
  • 越高打越遠，但波束越扁、仰角越窄。手持／移動未必越高越好。

③ 接頭規格

  • 常見 SMA-公 / SMA-母 / BNC…。
  • 母機與天線的公母、螺紋要對得上；接錯裝不上或接觸不良、功率漏失。
辨識法中央有針＝公、凹孔＝母，天線要和機身「相反」才鎖得上。SMA 與 RP-SMA 外觀近似、中央針／孔相反，買前務必先確認機身規格。
SESSION 5

寬頻 / 窄頻 W / N

面板寫「頻寬」，其實它設的是「訊號最多能佔多寬」的上限。

破除迷思　「面板寫頻寬，就是在設頻寬」 → 設的是寬度的天花板；實際多寬看你多大聲。

5·1為什麼要有寬 / 窄頻？

要解決的問題
頻譜不夠用。使用者暴增，主管機關必須在不新增頻譜下擠出更多頻道。
設計原理
把訊號寬度的天花板砍一半（窄頻），頻道間隔就能縮一半，同一段頻譜塞進兩倍頻道。
現場場景
代價是音質與訊噪比略降；跨單位務必統一 W 或 N，否則一個破音、一個太小聲。

5·2寬 / 窄頻 ＝ 訊號寬度的天花板

一句話W/N 設的是「最寬能到多寬」的上限；你講多大聲，決定實際走到哪。太小聲用不滿、太大聲會超出。
場景跨單位一邊寬一邊窄 → 聲音一個破一個太小，兩邊都以為是對方訊號弱。統一 W/N，寫進通聯計畫。
SESSION 6

頻道步進 Step

從「轉頻率的最小單位」，到「沒協調好就壓到隔壁」。

破除迷思　「步進只是調頻率的方便設定」 → 設錯會叫不到頻率，還會壓到隔壁。

6·1為什麼要有頻道步進？

要解決的問題
整段頻譜要切成整齊的「頻道格」，大家才停在同樣的位置上、不各停各的。
設計原理
步進＝頻道間隔的跳動單位；設對，才停得上格線、也才不會壓到鄰頻。
現場場景
叫不到某頻率（步進太大跳過了）、或被鄰頻抱怨干擾 → 都先查步進。

6·2步進：轉頻率的最小跳動單位

步進 (STEP) ＝ 你每按一下、轉一格，頻率跳動的最小量。常見 5 / 6.25 / 12.5 / 25 kHz。整個頻段被它切成一格一格。

✗ 步進 25 kHz

  • 停得到：145.000 / .025 / .050 / .075 / .100
  • 停不到 145.0125（被跳過）

✓ 步進 12.5 kHz

  • 停得到：…145.000 / .0125 / .025 / .0375 / .050…
  • 145.0125 剛好落在格線上
一句話聽得到卻停不上去，八成是步進設太大——先查步進，再懷疑天線。

6·3步進沒協調 → 鄰頻重疊；為什麼留「保護頻帶」

真實訊號會超出「理論／佔用頻寬」——邊緣的「裙擺」向外溢。保護頻帶 ＝ 頻道間隔 − 佔用頻寬，就是留給裙擺的緩衝，算出負數＝必定重疊。

設定頻道間隔保護頻帶結果
寬頻 16k25 kHz+9 kHz安全
寬頻 16k12.5 kHz−3.5 kHz重疊
窄頻 11k12.5 kHz+1.5 kHz勉強

裙擺

  • 真實訊號會超出理論頻寬——邊緣還有能量。

漂移

  • 發射頻率會隨溫度、晶體誤差飄，不會永遠停在正中央。

濾波器

  • 接收濾波器不是磚牆，邊緣慢慢滾降，鄰頻會漏一點進來。
FM 要多寬才夠？寬頻 25k − 16k ＝ 9k（夠）；窄頻 12.5k − 11k ＝ 只剩 1.5k——所以窄頻對頻率準確度與濾波器要求更嚴。
動手做 · 分組實作

調出這個形狀

一對無線電、兩種設定，在頻譜上疊出「一寬一窄」——這就是你這組要做出來的畫面。

每組拿到一段夠寬的頻段，兩台就在裡面錯開頻率。全部落在 2m 頻段內、避開呼叫與衛星頻率。

題目兩台一起發，疊出一寬一窄

做法

  • A 台　寬頻 (W) ＋ 低功率 (L)
  • B 台　窄頻 (N) ＋ 高功率 (H)
  • 錯開　兩台頻率在你們的頻段內稍微分開
  • 疊圖　開 SDR 的 FFT Hold，兩台輪流發

想一想

  • 哪個佔的頻寬大？哪個比較高（訊號強）？
  • 兩台靠太近會怎樣？
  • 高度看功率、寬度看 W/N，兩件事互不相干——這正是判斷「同一個頻段裡有幾台、各是什麼設定」的基本功。
SESSION 7

亞音 CTCSS

重點：亞音不是加密。

破除迷思　「設了亞音＝私人頻道，別人聽不到」 → 它一點都不加密，只關你自己的喇叭。

7·1為什麼要有亞音（CTCSS）？

要解決的問題
同一個頻率常要多組人共用。你不想整天聽到別組的通話與雜音。
設計原理
發射端蓋一個「暗號」（次音頻），收端只對暗號開喇叭——這是分群，不是加密。
現場場景
中繼台要正確亞音才會開；但你講的每句話仍是明語，任何人、任何 SDR 都收得到。

7·2亞音在瀑布圖上：一排梳齒

一句話梳齒間隔 ＝ 亞音頻率。不用問你，數格子就讀得出你設的是幾赫茲（實測誤差 ≤1.4%）。

7·3亞音不是加密——它只關你的喇叭

同一個電波（總功率差 0.58 dB、頻寬差 10 Hz），B 卻一個聽得到、一個聽不到。而且 B 不出聲時 BUSY 燈仍亮著——它自己承認收到了，只是不放給你聽。

通聯紀律人員位置、傷患個資、物資數量——設了亞音也一樣不能明語講。

動手做設傳 / 收亞音，體驗通聯差異

兩台 A / B 對到同一頻率。分開設「發射碼 T-CTCS」與「接收碼 R-CTCS」，走四種組合，觀察通不通。收碼＝收聽要不要「驗」亞音；傳碼＝發射要不要「帶」亞音。

各組亞音第 1 組 88.5 Hz · 第 2 組 100.0 Hz …（各組不同碼，同頻分群）。

SESSION 8

Offset　收發分裂

「offset 改的是我收聽的頻率」 → 不，offset 只在按 PTT 發射時生效；你顯示／收聽的頻率不動。

重點：中繼台一收一發不同頻。offset 決定「發射」跳去哪——方向(＋/−)＋大小；還要配亞音才進得了中繼台。

8·1為什麼要 offset？中繼台一收一發

要解決的問題
中繼台要「同時」聽你講、又把你的話轉播出去。若收發同頻，它一發就會蓋掉自己正在收的訊號（自我干擾），根本無法運作。
設計原理
讓中繼台「收一個頻率、發另一個頻率」，兩者相差固定的 offset（2m 常見 −600 kHz）。你的機器：顯示／收聽＝中繼台輸出；一按 PTT 自動平移 offset ＝中繼台輸入。offset 只動 TX，不動 RX。
現場場景
打不進中繼台，先查三件事：頻率（輸出對不對）、offset（方向＋大小）、亞音（CTCSS）。三者缺一不可——只設 offset 數值卻沒設方向（＋/−），機器根本不會平移。

8·2offset 實測：TX 平移、RX 不動

RX

  • 顯示／收聽 145.050　＝中繼台輸出（不動）

TX

  • 145.050 ± offset　＝中繼台輸入（按 PTT 才平移）
看圖紅線＝你設定的 145.050（RX 不動）；黃色載波＝按 PTT 的發射位置，隨 offset 左右平移。實測用 ±10 kHz 小偏移才同框看得到；真實中繼台常 ±600 kHz，要把 SDR 頻寬開大才看得到跳到哪。
想一想

架一座 2m 中繼台

中繼台「同時收、同時發」（全雙工）。先想清楚：最少要設定什麼才能通話？

中繼台在做什麼？

  • 兩台手持機互相聽不到（太遠、被山擋）就不能直通。
  • 中繼台架在高處，同時「收」、再用另一個頻率「發」，替大家轉發——把每個人的涵蓋範圍放大到中繼台看得到的地方。

什麼時候用？

  • 手持直通常只有幾公里、怕地形遮蔽。山區搜救、跨市聯絡、災難現場，靠一座山頂中繼台就能把分散的小隊連起來。
  • 注意：它一倒，靠它的人全斷——要留直通備援。

SESSION 9

靜噪 Squelch

「靜噪把訊號關掉了」 → 它只關你的喇叭，電波照舊、別人照收。

9·1為什麼要有靜噪？

要解決的問題
沒訊號時，收音機會一直發出白噪音「沙沙聲」。你不想整天聽它，也不想手動去關喇叭。
設計原理
設一個「訊號強度門檻」：低於門檻就把喇叭關掉、高於門檻才出聲——它只關喇叭，不動電波。可再加亞音當第二道條件，只對暗號開喇叭。
現場場景
設太高→弱訊號漏接（以為沒人）；設太低→一直有雜音。收不到時先想：是靜噪太高還是真沒訊號？用 SDR 瀑布圖一看便知——有訊號卻沒聲＝靜噪太高。

9·2靜噪：在「底噪」之上，畫一條門檻線

底噪＝背景雜訊的高度；靜噪 SQL＝你在底噪之上畫的一條門檻線。訊號高過線→喇叭開；低於線（含底噪）→喇叭關。

太高
門檻拉到訊號之上 → 連訊號都擋掉＝漏接（有人也聽不到）
剛好
門檻在底噪之上、訊號之下 → 雜音關、真訊號一來就開 ✔
太低
門檻壓進底噪裡 → 雜音漏出來＝一直沙沙
它只關喇叭、不動電波你這裡沒聲，不代表別人沒收到——SDR、沒設靜噪的人照樣收得到（跟亞音「不是加密」同一個道理）。

動手做調 SQL 找門檻（用低功率）

各組甲聽、乙發（同頻率）。把 SQL 從 0 慢慢往上轉，看喇叭：一直響 → 只在乙發時響 → 連乙發都不響。弱訊號用低功率 (L)做。

測試甲的 SQL乙發射甲喇叭體驗／學到
①SQL 0（全開）沒人發一直沙沙太低＝整天雜音
②調到雜音剛消失沒人發安靜這個值＝「門檻」（設在底噪之上）
③維持門檻乙近距·正常發出聲、清楚設對：安靜又收得到
④SQL 轉到最高乙轉低功率 L 發聽不到（漏接）太高＝有人也漏接；SDR／BUSY 仍看得到
⚑ 收不到先分辨「靜噪太高」還是「真的沒訊號」？按 MONI（監聽）或看 SDR 瀑布圖——有訊號卻沒聲＝靜噪太高。
