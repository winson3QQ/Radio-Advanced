SESSION 2 · 頻率 9/54

為什麼要對頻率？

  • ★ 頻率對不上，其他全部免談——這是通訊的第一道門
  • 空中同時有無數訊號。你要跟誰通，就得先和對方站到「同一個頻率」上。
  • 要解決的問題
  • 頻率＝事先約好的碰面地點；雙方對齊，才聽得到彼此。功率、天線都是之後的事。
  • 設計原理
  • 聽得到卻叫不到 → 先核對頻率與末位數字，比換天線、加功率都優先。
  • 現場場景
SESSION 2 · 頻率 10/54

頻率 ＝ 水平位置

  • 轉一個頻道，那根線就往右跳一格 →
  • 144.900 MHz
  • 145.000 MHz
  • 145.050 MHz
  • 一句話 頻率就是這根線的左右位置。聽得到卻叫不到，先查頻率末位數字，比查天線還優先。
SESSION 2 · 頻率 11/54

VHF 與 UHF：住在頻譜的哪裡

  • VHF · 30 – 300 MHz
  • UHF · 300 MHz – 3 GHz
  • ← 頻率低 · 波長長
  • 頻率高 · 波長短 →
  • 2m 業餘段 144 – 148 MHz
  • 70cm 業餘段 430 – 440 MHz
  • 波長 λ = 光速 c ⁄ 頻率 f
  • 145 MHz · λ ≈ 2.07 m · ＝「2 米」段
  • 435 MHz · λ ≈ 0.69 m · ＝「70 公分」段
  • c ≈ 3 × 10⁸ 公尺/秒。頻率越高，波長越短。
  • ※ 頻譜條為示意，非等比例。業餘無線電的兩個主力頻段，一個在 VHF、一個在 UHF。
  • 一句話 波長由頻率決定；波長決定了天線多大、以及電波怎麼傳——這是下一頁的重點。
SESSION 2 · 頻率 12/54

波長長短，各有各的場子（理論上）

  • VHF · 2m 波長長（約 2 公尺）
  • UHF · 70cm 波長短（約 0.7 公尺）
  • 繞射強　能繞過山丘、地形起伏
  • 直線性強　靠反射鑽進建築、走廊
  • 開闊佔優　郊區、野外傳得更遠
  • 穿透雜亂　市區、室內、大樓密集佔優
  • 天線較長　但增益容易做出來
  • 天線較短　頻寬也較充裕
  • 適合　山區、野外、長距離
  • 適合　都市、室內、複雜地形
  • 一句話 沒有哪個「比較好」——看你在什麼環境。這是理論；真實世界還有下一頁的變數。
SESSION 2 · 頻率 13/54

但理論歸理論：電波在真實環境會被折騰

  • 多路徑 Multipath
  • 反射 Reflection
  • 同一訊號走不同路徑到達，彼此相加相消 → 忽強忽弱
  • 牆面、金屬、水面把電波彈開，產生第二條路徑
  • 折射 Refraction
  • 散射 Scattering
  • 大氣與對流層讓路徑彎曲，訊號方向偏掉
  • 雨、樹葉、粗糙表面把能量打散到四面八方
  • 繞射 Diffraction
  • 吸收 / 遮蔽 Absorption
  • 從山稜、建築邊緣繞過去，障礙後也收得到一點
  • 牆體、人體、雨水吸掉能量，大障礙後形成陰影
  • 這些加起來 ＝ 訊號飄移、衰落、時好時壞。 「理論上更好」≠「現場更好」——走幾步、轉正天線就不同。先看，再猜。
SESSION 2 · 頻率 14/54

近代想辦法克服——但 FM 是類比

  • 近代數位通訊怎麼對付不穩定
  • 業餘 FM 手持機 ＝ 類比，沒有這些
  • 數位調變 + 錯誤更正 (FEC) · 收到有錯，靠冗餘碼自己補回來
  • 簡單、堅固、低延遲的即時語音
  • 不需要基地台或網路就能通
  • 展頻 / OFDM · 把資料攤到多個載波，避開被打爛的頻段
  • 跨廠牌互通，靠人與紀律運作
  • 分集 / MIMO · 多支天線同時收，挑最好的那條路
  • 當基礎設施倒下，它還會動 ← 民防/災害的最後手段
  • 自適應編碼 + 重傳 · 通道差就降速、要求重送
  • 抗噪靠 FM 捕獲效應，不靠演算法——訊號差就是差。所以前面每個參數都得調對。
  • 一句話 業餘無線電的定位：在最壞情況下——沒電、沒網、沒基地台——仍然會動的通訊。
SESSION 3 15/54

發射功率 TX Power

  • H / M / L —— 功率大，只是線更亮
  • 破除迷思
  • 「功率越大越好」　→　夠用就好；大只是更耗電、更燙、干擾更廣
SESSION 3 · 發射功率 16/54

為什麼要有 H / M / L？

  • 訊號會隨距離變弱。功率決定你「推得多遠」，但推得越遠，也干擾越廣、越耗電。
  • 要解決的問題
  • 給你 H / M / L 三段可選，讓你按需要挑——夠用就好，不是越大越好。
  • 設計原理
  • 近距離用 L：省電、少干擾、機殼不燙；只有邊緣地帶才加到 H。
  • 現場場景
SESSION 3 · 發射功率 17/54

發射功率 ＝ 高度 / 亮度（寬度不變）

  • 示意：H 高又亮、L 矮又暗，但左右寬度一樣
  • 功率大 ＝ 訊號更高、更亮，但左右寬度完全不變。 · 通不通，還要看對方收不收得到——加功率不保證通。
  • Δ 高度 · ＝ 亮度
  • H
  • L
  • ← 同樣的寬度 →
  • 實測 H　峰值 −47 dB
  • 實測 L　峰值 −51 dB
  • 實測（Narrow 窄頻，加 −20 dB 衰減）　H 高功率峰值約 −47 dB、L 低功率約 −51 dB——高度差看得出來（功率＝高度／亮度），而左右寬度一樣。先把訊號拉離天花板（衰減／拉遠），H 與 L 的差異才顯現。
SESSION 4 18/54

天線 Antenna

  • 增益 ＝ 把功率集中打出去；頻率、接頭要對得上
  • 先想清楚
  • 「天線隨便接就好」　→　頻率要對、增益看場景、接頭要對得上，接錯就白費功率
SESSION 4 · 天線 19/54

天線增益實測：換一支天線，載波差約 13 dB

  • 短天線 Ant1　→　峰值 −42 dB
  • 長天線 Ant3　→　峰值 −29 dB
  • 長 − 短 · ≈ 13 dB · 長天線把能量集中 → 載波明顯更強
  • 替換法量測條件
  • MTS 發純載波 145.050 MHz（Wide／低功率／−20 dB 衰減）；RTL-SDR 固定接收（Gain 0、AGC 全關）。 · 只換發射端天線、其他不動，讀 FFT 峰值相減。兩張噪聲底一致（約 −100 dB）＝條件相同。
  • 左 短天線(Ant1)　右 長天線(Ant3) · 同軸接同一台 MTS 發射
  • 註　這是室內相對讀數（含短天線效率低＋近場/反射），非 dBi 認證增益值；但「長 > 短」順序正確，符合『天線越長、增益越高、載波越強』。要認證數字需室外遠場。
SESSION 4 · 天線 20/54

挑天線看三件事：頻率、增益、接頭

  • 1
  • 2
  • 3
  • ① 短　② 中（標示 FM 136–174 / 400–480MHz ＝ V/U 雙頻）　③ 長　辨識：中央有針＝公、凹孔＝母，天線要和機身「相反」才鎖得上。
  • ① 頻率
  • ② 增益(gain)
  • ③ 接頭規格
  • 天線有設計頻段（例：標示 FM 136–174 / 400–480MHz ＝ V/U 雙頻）。用在對的頻段才有效率；不對會駐波比(SWR)高、功率被反射回機身。
  • 常見 dBi / dBd（dBd＝dBi−2.15）。越高打越遠，但波束越扁、仰角越窄。手持/移動未必越高越好。
  • 常見 SMA-公 / SMA-母 / BNC…。母機與天線的公母、螺紋要對得上；接錯裝不上或接觸不良、功率漏失。
  • 接頭要對得上　這三支都是 SMA 類接頭但公母/螺紋未必相同——母機與天線要「公對母」才鎖得上、接觸才好。SMA 與 RP-SMA 外觀近似，中央針/孔相反，買前務必先確認機身規格。
SESSION 5 21/54

寬頻 / 窄頻 W / N

  • 面板寫「頻寬」，其實它設的是「訊號最多能佔多寬」的上限
  • 破除迷思
  • 「面板寫頻寬，就是在設頻寬」　→　設的是寬度的天花板；實際多寬看你多大聲
SESSION 5 · 寬窄頻 22/54

為什麼要有寬 / 窄頻？

  • 頻譜不夠用。使用者暴增，主管機關必須在不新增頻譜下擠出更多頻道。
  • 要解決的問題
  • 把訊號寬度的天花板砍一半（窄頻），頻道間隔就能縮一半，同一段頻譜塞進兩倍頻道。
  • 設計原理
  • 代價是音質與訊噪比略降；跨單位務必統一 W 或 N，否則一個破音、一個太小聲。
  • 現場場景
SESSION 5 · 寬窄頻 23/54

寬 / 窄頻 ＝ 訊號寬度的天花板

  • 寬頻 W：天花板高，最寬可到約 16 kHz
  • 窄頻 N：天花板低，最寬約 11 kHz
  • 一句話 W/N 設的是「最寬能到多寬」的上限；你講多大聲，決定實際走到哪。太小聲用不滿、太大聲會超出。
  • 場景　跨單位一邊寬一邊窄 → 聲音一個破一個太小，兩邊都以為是對方訊號弱。統一 W/N，寫進通聯計畫。
SESSION 6 24/54

頻道步進 Step

  • 從「轉頻率的最小單位」，到「沒協調好就壓到隔壁」
  • 破除迷思
  • 「步進只是調頻率的方便設定」　→　設錯會叫不到頻率，還會壓到隔壁
SESSION 6 · 步進 25/54

為什麼要有頻道步進？

  • 整段頻譜要切成整齊的「頻道格」，大家才停在同樣的位置上、不各停各的。
  • 要解決的問題
  • 步進＝頻道間隔的跳動單位；設對，才停得上格線、也才不會壓到鄰頻。
  • 設計原理
  • 叫不到某頻率（步進太大跳過了）、或被鄰頻抱怨干擾 → 都先查步進。
  • 現場場景

SESSION 8 · Offset 38/54

為什麼要 offset？中繼台一收一發

  • 中繼台要「同時」聽你講、又把你的話轉播出去。若收發同頻，它一發就會蓋掉自己正在收的訊號（自我干擾），根本無法運作。

  • 讓中繼台「收一個頻率、發另一個頻率」，兩者相差固定的 offset（2m 常見 −600 kHz）。你的機器：顯示／收聽＝中繼台輸出；一按 PTT 自動平移 offset ＝中繼台輸入。offset 只動 TX，不動 RX。

  • 打不進中繼台，先查三件事：頻率（輸出對不對）、offset（方向＋大小）、亞音（CTCSS）。三者缺一不可——只設 offset 數值卻沒設方向（＋/−），機器根本不會平移。

SESSION 9 · 靜噪 44/54

靜噪：讓喇叭閉嘴，但電波照舊

  • 沒訊號時，收音機會一直發出白噪音「沙沙聲」。你不想整天聽它，也不想手動去關喇叭。
  • 要解決的問題
  • 設一個「訊號強度門檻」：低於門檻就把喇叭關掉、高於門檻才出聲——它只關喇叭，不動電波。可再加亞音(CTCSS)當第二道條件，只對暗號開喇叭。
  • 設計原理
  • 設太高→弱訊號漏接(以為沒人)；設太低→一直有雜音。收不到時先想：是靜噪太高還是真沒訊號？用 SDR 瀑布圖一看便知——有訊號卻沒聲＝靜噪太高。

參考答案：新竹地震通訊計畫這樣配

  • 條件
  • 參考答案（範例）
  • 為什麼
  • 頻率與步進
  • 各隊分配不同頻率、步進統一 12.5k；跨隊經中繼台一進一出
  • 頻率錯開不互壓、步進統一避免鄰頻重疊(S6)
  • 寬 / 窄頻
  • 全體窄頻 N
  • 頻道多、可容納更多隊，語音夠用(S5)
  • 功率
  • 指揮所／中繼台 H；隊員平時 L
  • 覆蓋 vs 省電；功率非萬靈丹(S3)
  • 亞音
  • 各隊不同入口亞音分隊；傷患個資不上明語
  • 擋誤觸、分群(S7)；業餘頻段禁加密
  • 天線與架設
  • 指揮所／中繼台高增益且架高；隊員原廠短天線
  • 天線效益 > 加功率(S4)
  • 中繼台
  • 架一座 2m 中繼台：145.700／−0.6／設入口亞音
  • 手持直通蓋不住山區，中繼台延伸覆蓋(想一想)
  • 資料鏈路與韌性
  • 位置用 Meshtastic(太陽能)；TAK 走 802.11；中繼台倒了退回直通
  • 語音+資料分工、避免單點失效(第二節)
